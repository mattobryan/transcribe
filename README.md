# English-Swahili Code-Switching Transcriber

A custom speech-to-text transcriber designed for English-Swahili code-switching speech patterns commonly found in Kenya.

## Features

- Handles mixed English-Swahili speech recognition
- CNN-LSTM architecture with attention mechanism
- Support for code-switched vocabulary
- Evaluation metrics including WER, CER, and BLEU scores

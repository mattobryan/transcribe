Add a recording

Step 1. Transcribe it in ElevenLabs with these settings
  1. elevenlabs.io → Developers → Speech to Text API (the playground), POST /v1/speech-to-text.
  2. model_id: scribe_v2 (not the medical one; scribe_v1 if v2 is not listed).
  3. diarize: true — so the two voices are separated into I: and R:.
  4. timestamps_granularity: word — needed for the chunks and the language labels.
  5. tag_audio_events: false — no "[laughter]" tags in the text.
  6. language_code: leave empty — Swahili and English are mixed, so let it detect.
  7. Optional keyterms (about $0.05 per hour extra): words you expect. Edit the list, then add them one by one.
  8. Upload the audio, Run request, then copy the whole response.
